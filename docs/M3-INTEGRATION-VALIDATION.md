# M3 — интеграционная проверка

12 октября 2026. Реализован согласованный графический сетевой срез; это не полная игра и не завершённая ручная приёмка Chrome.

## Поставлено

- Отдельный режим `--mode m3`, protocol 2, metadata-манифест точной 4.5.2; M2 остаётся режимом по умолчанию.
- Локальный импорт 44 файлов в Worker, проверка hash/digest, отмена и атомарная публикация профиля. Нет отправки игровых файлов на сервер и постоянного кеша.
- Three.js/WebGL2: галактика, системы, оригинальные статические модели корвета/станции/планеты/звезды, локальные иконки, тест 200 корветов. Материалы приближённые, не оригинальные шейдеры.
- Лобби двух игроков и наблюдателя, готовность профиля, передача прав, собственные приказы флота, точный календарь, пауза/скорости/шаг дня, месячная экономика и отдельное содержание профессий/зданий.
- Защита от повторов команд, фильтрация приватных данных, переподключение в ту же живую сессию. Перезапуск завершает партию; сохранений и боя нет.

## Выполненные проверки

Основной агент повторил полный Node-прогон с `STELLARIS_GAME_ROOT`, указывающим на локальную 4.5.2: **107/107 PASS, 0 SKIP**. Включены прежние M2 connection regressions, настоящий профиль/Worker pipeline, renderer ownership и 100 переключений, UI handlers, reconnect/очередь/тайм-ауты, потеря контекста и default browser timer receiver. GPU в unit tests заменён проверяемым adapter; это не измерение VRAM/FPS.

Повторные C# проверки: **68** пространственных/календарных проверок, **14** наборов M3-сессии, **7** M2-сессии и **7** M1 с реальным контентом — PASS. Атомарность месячного шага проверена вместе с движением; экономическая ошибка не оставляет частичный spatial/economy commit. JSON unions, скрытые ссылки, права и реальная связь колонии с planet ID 1/4 проверены.

Прежний M2 HTTP/WebSocket harness повторён против нового серверного бинарника в отдельном режиме m2: PASS (два игрока/наблюдатель, vanilla trait, права, повторы, возврат, передача хоста и раздельный upkeep). Временный сервер остановлен после проверки.

Серверный manifest: **9 PASS, 1 SKIP**, canonical digest сверён настоящим JS validator. Детерминированно проверены same-length подмена между hash-pass, неизменённый контроль, отмена/освобождение handles и отказ без частичного manifest. Windows junction root/ancestor/internal-path — PASS на synthetic fixtures; единственный SKIP — отдельное создание symlink недоступно. Основной агент повторил разрешённый запуск вне sandbox, независимое ревью без существенных замечаний. Детали среды/безопасной очистки — [проверки metadata](M3-CORE-VALIDATION.md).

Независимое ревью клиента/транспорта после исправлений: существенных оставшихся замечаний не обнаружено. Найденная при предварительном браузерном входе ошибка `Illegal invocation` у default setInterval исправлена; отдельная регрессия проверяет receiver глобальных таймеров без injection.

HTTP/WebSocket M3 harness: **164 PASS**, Release build **0 warnings/errors**. Проверены manifest44/отсутствие raw asset endpoint/CSP, protocol и код доступа/Origin, readiness/двое игроков/start/step/duplicate ACK, публичное пространство и приватная экономика, собственный/чужой флот, возврат с прежним token и сброс assetReady, запрет позднего наблюдателя и shutdown. Восемь одновременных сокетов допускаются, девятый получает HTTP 429; реальный клиент без join отключается за 10 секунд (проверенная граница 9–14 с). Pure checks также проверяют strict JSON/UTF-8/лимиты размера/FIFO64/последний snapshot/rolling rate.

Последние девять проверок: real HTTP принимает uppercase LOCALHOST, отвергает чужой Host; управляемый WebSocket double вызывает закрытые production SendAsync/SendLoopAsync через reflection, подтверждает deadline 3 с, переданный cancellation token, внешнюю отмену, oversized до socket call, FIFO ответов/последний snapshot и ровно одну конкурентную отправку. Независимое ревью подтвердило, что watchdog не подменяет production timeout. Production API ради теста не расширен.

Предварительный осмотр встроенным браузером Codex: настоящий module Worker завершил импорт 44 локальных File за **4,82–5,00 с**, decoded **217,6 MiB**; два игрока подключились к лобби. Статические модели ранее отдельно осмотрены в preview — [отчёт](M3-IMPORT-VALIDATION.md). Это не Google Chrome и не полный трёхклиентский игровой сценарий.

## Pending, не PASS

- Ручной Chrome: три клиента, настоящие folder grant/cancel/revoke, карта/жесты/приказы/месяц/reconnect и WebGL context restore.
- Chrome 1080p: 60 FPS базовой сцены и p95 ≤33,3 мс для 200 корветов; фактические RAM/VRAM и длительная нагрузка.
- Физический TCP slow-reader/исчерпание сетевых буферов. Production send deadline и send-loop проверены детерминированно, но это не испытание физической медленной сети.
- Физическая LAN и целевое минимальное оборудование. M3 намеренно только localhost.

Ручная приёмка не блокирует поставку доступно проверенной реализации по последующему прямому указанию пользователя. Инструкция: [запуск и сценарии](M3-RUN-AND-TEST.md).
