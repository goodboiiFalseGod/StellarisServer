# Оригинальная локализация

Задача LOC-001, 13 октября 2026: по прямому поручению пользователя игровые подписи и описания берутся из локальной установки Stellaris 4.5.2 по оригинальным ключам. UI и каталоги имеют отдельных владельцев; этот этап поставляет изолированный клиентский модуль и согласованные точки подключения, не меняет игровую механику.

## Контракт

- Каждый браузер читает свой уже выбранный read-only источник `{mode:'files', files}` или `{mode:'directory', handle}`. Байты и переводы не отправляются серверу, не включаются в Git и не сохраняются в постоянный кеш. Читаются только фиксированные 232 относительных имени из `m3-localization-paths.mjs` для `localisation/russian` и резервного `localisation/english`; отдельно поддержан English без русского. Имена сверены между двумя папками установленной 4.5.2; это профиль путей, не доказательство неизменности байтов всей установки. Моды, `replace` и `localisation_synced` не входят в профиль. По прямому ответу пользователя RINFIX исключён; его и любые дополнительные файлы reader не читает.
- `loadLocalLocalization(source, {language, signal})` атомарно возвращает снимок. Ошибка, отмена и новый импорт не заменяют прежний снимок; публикацией владеет существующий UI import lifecycle. При reload нужен новый импорт. Неподдержанный язык, опасный путь, дубликат пути, отсутствие обязательного файла, некорректный UTF-8 или превышение бюджета дают явную ошибку с code/path. Ограничения: 464 файла, 16 MiB на файл, 64 MiB суммарно, 250000 уникальных ключей. Texture-only File source даёт `missing-source`; UI предлагает выбор папки, не объявляя локализацию доступной.
- Парсер читает BOM, заголовок `l_language:`, необязательную числовую версию, строки в кавычках с экранированием и комментариями; поддерживает встречающиеся в штатных файлах внутренние неэкранированные кавычки. Это формат Paradox, не общий YAML. Некорректные строки диагностируются с относительным путём и номером строки; диагностик не более 1000. Неверный заголовок отклоняет загрузку. Неизвестная escape-последовательность сохраняется.
- Порядок детерминирован: фиксированные относительные пути по ordinal-сравнению; последняя запись побеждает. Это ограниченная политика браузерного читателя; полное совпадение всех конфликтов с native loader не заявляется. Повторные ключи отражаются в диагностике. Сначала загружается English, поверх выбранный язык; English служит fallback только отсутствующему ключу.
- Снимок предоставляет `resolve(key, {parameters}) -> {text, diagnostics}`, `text(key, fallback) -> string` и `raw(key) -> string|undefined`, а также статистику и диагностику загрузки. `raw` сохраняет исходный шаблон с разметкой для будущего rich renderer. Разрешаются рекурсивные `$KEY$` и явно переданные параметры; циклы, отсутствующие ссылки, глубина >32, >10000 раскрытий и результат >65536 символов диагностируются. Scope-выражения `[Root.GetName]` не исполняются и остаются видимыми. Параметры — текст, не HTML и не исполняемые скрипты. Числовое форматирование, грамматика `&gen`/составных имён и scripted localization не исполняются; неподдержанный формат диагностируется, исходный шаблон доступен через `raw`.
- Текст для DOM не содержит HTML-интерпретации. Для plain-text подписей удаляются маркеры цвета `§X`/`§!`, иконки `£id£` заменяются читаемым `[id]`, формат `$KEY|Y$` разрешается без цвета. Исходные scope/неизвестные ссылки остаются видимыми. Богатая разметка и icon renderer — отдельное подключение владельца UI.
- Каталог передаёт оригинальные `localizationKey` и `descriptionKey` по исходному определению, включая job swaps; сервер не передаёт переводы. Не выводить оригинальный ключ из русского имени или псевдонима лаборатории. Для определения, где оригинальный ID уже является ключом, UI может передать этот ID напрямую. Для собственных статусов прототипа сохраняются собственные русские сообщения; они не маскируются под строки игры.
- Экран исследований общего кандидата подчиняется тому же контракту: названия/описания технологий, исходные категории и подписи игровых эффектов разрешаются браузером. Сервер передаёт проверенные ключи и структурированные значения эффекта/ID открываемого здания; оригинальные переводы с сервера не передаются. Серверный reader всех `*_l_russian.yml` не допускается, в том числе из-за захвата исключённого RINFIX. Активное исследование, предложения, изученные технологии, сообщение о завершении и доступное имя иконки используют один локальный словарь. Неизвестный эффект явно диагностируется; собственные статусы «Действует/Отложено» остаются сообщениями прототипа.

## Приёмка

Проверить синтетическими данными формат/escaping/ссылки/циклы/параметры/безопасный plain text и raw, fallback, одинаковый результат двух способов выбора источника, отмену, путь/дубликаты/лимиты и исключение дополнительных файлов. Отдельный opt-in тест читает реальную установку без записи оригинального текста в отчёт или Git. Независимый reviewer читает фактический diff. UI owner подключает callback `resolveLocalization(key, fallback)` и staging вместе с графическим импортом; catalog owner передаёт исходные keys. Реальная браузерная приёмка и совместная интеграция отмечаются отдельно от тестов модуля.

Уточнение пользователя: работу интегратора не завершать до прохождения всех UI-проверок. Следующий gate относится к одному неизменному потребительскому commit и затем к общему кандидату; смена кода инвалидирует затронутые результаты. В отчёте фиксируются commit, URL тестового экземпляра, размер окна, реальные/синтетические источники и результат каждого сценария:

Уточнение координатора общего кандидата 14 октября: для реального профиля около 327 MiB и лимита 512 MiB обязательны успешный первоначальный полный импорт и явный отказ повторного полного декодирования с сохранением прежних CPU/GPU/локализации. Положительная горячая замена двух полных наборов не входит в этот срез и не объявляется проверенной. Лимит не увеличивается, locale-only обход проверки источника не добавляется. Новый первый импорт после reload остаётся обязательным; синтетический малый профиль подтверждает условную ветку успешной публикации, а не живую замену полного набора.

1. Локальный read-only folder import: графика и все 464 файла EN/RU публикуются вместе; статус показывает локализацию, язык/число ключей/диагностику. RINFIX не читается. Reload требует нового импорта.
2. File import: объединённый выбор графики и локализации разделяется на точные наборы потребителей; texture-only выбор показывает `missing-source` и способ выбрать папку, не публикуя частичный набор.
3. Верхняя панель и окно колонии: ресурсы, исходные имена/описания зданий, районов, зон, профессий и планетных особенностей, статические игровые заголовки получают original keys. Job aliases/swaps используют подтверждённые metadata, а не угадывание префикса или приоритет нелокализованного server.name.
4. Открытое окно перерисовывается после успешной смены источника, если staging помещается в бюджет; отмена/ошибка/устаревшее завершение импорта сохраняют прежние графику и словарь. Для полного текущего профиля отдельно проверить ожидаемый отказ повторного декодирования по бюджету. Закрытие/logout не допускают поздней публикации. Reconnect и смена допустимого POV не возвращают нелокализованные подписи и не раскрывают чужие данные.
5. Ссылки, параметры, отсутствующий ключ и неподдержанный scope/format дают ожидаемый читаемый plain text и диагностику. Игровой текст с HTML-подобными фрагментами выводится как текст, без создания HTML-элементов. Исходная разметка остаётся доступной через `raw`.
6. Реальная браузерная проверка 16:9 подтверждает видимые подписи, описания, доступные tabs/close/строительные действия и отсутствие перекрытий от длины русских строк. Согласованные UI-регрессии, независимое ревью и общий QA должны пройти; module tests не заменяют этот gate.
