# Personal outliner and observer perspectives

Direct user requirement, 12 October 2026, orchestrator turn `01a13060-27dc-7262-a858-b7feaaa38a85`: each player's outliner is personal; an approved observer switches player POVs or a general view without an outliner. Visual acceptance remains open. This supersedes generic all-map outliner assumptions in the reference/UI contracts.

## Required projection and authority

Players receive their existing server-authorized player projection and a personal outliner containing only their owned colonies, fleets and supported owned station/body entries. The full map is navigable separately; do not list all systems or foreign assets as personal assets. Source DTO ownership determines membership, not names or cached data.

The current M3 fixture deliberately exposes all system/body positions publicly. M3Projection already withholds foreign economy links and movement orders from players. Do not invent native fog/discovery rules. Observer player POV must use that same server projection/economic filtering as the selected player; identical public map positions are expected in this fixture, while private economy, colony links and movement fields differ. Future visibility filters must use the same player projection path, not a parallel omniscient client filter.

Approved observers default to general view: existing authorized observer overview, personal outliner hidden. Player POV identifies one existing player (including offline players still in this live session), displays that player's personal outliner/resources and permitted map data, and remains read-only. Actual snapshot `you`, token, role, host identity and every command authorization remain the observer's. Display identity must be separate from control identity. Ordinary players and pending observers cannot choose another POV or obtain another player's private data.
