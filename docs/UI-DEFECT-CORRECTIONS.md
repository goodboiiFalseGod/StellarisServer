# Исправление UI по ревью 14 октября 2026

Основание: [32 замечания](reports/ui-reference-review-2026-10-14.md), прямое поручение пользователя исправить недостатки. База — `2e82630` (код RC `323f025`). Только собственная ветка; активные серверы и основной checkout не изменять.

Реализация и ограничения: [отчёт проверок](reports/ui-defect-corrections-2026-10-14.md). Частичные пункты не считаются закрытыми.

## Контракт до реализации

- HUD: основные ресурсы, потоки и время видны без горизонтальной прокрутки на 1280×720 и 1920×1080; редкие ресурсы доступны в раскрытии. Неизвестное остаётся неизвестным. Читаемый текст, компактная связь, явные pending/error/stale; подтверждения доступны вторым уровнем.
- Карта: far показывает важные метки (выбор, hover, домашние и маршрут); near раскрывает остальные. Системные метки разрешают пересечения по приоритету. Классы звёзд меняют только представление, фон не подавляет объекты. Picking, координаты, ownership и приказы сохраняются. Обзор системы учитывает реальные видимые тела; выходы остаются достижимы zoom/pan.
- Имена: технический класс не выдавать за имя планеты. При отсутствии уникального имени показать честную локализованную подпись с идентификатором объекта и отдельно класс; исходный ключ доступен в диагностике. Серверные имена не переписывать.
- Флот: существующий состав, фаза и цель первичны, маршрут и отсутствие ETA вторичны. Неполученные здоровье/мощь/лидер не имитировать.
- Планета: компактный явный fallback панорамы; пропорциональное окно и контекст. Производство/расход полученного закрытого месяца видны сразу. Шкалы районов только по полученным capacity/pools; шкала профессии по полученным значениям, единицы не пересчитывать. Сохранить ±5%, Shift, черновик, focus, observer и запреты. Категории обозначают число типов, используют полученный class icon. Особенности в двух связанных областях. Состояния очереди русские, IDs в раскрытии, действия сохраняют реальные IDs.
- Исследования: прямой вход в изученные; цветные заголовки и отдельная стоимость. Краткие эффекты, полный текст/причины deferred в раскрытии с видимым признаком ограничения. Постоянный размер fallback иконки и единое действие выбора источника. Компактная доступная кнопка выбора сохраняет текущую семантику (native click не доказан). Фильтры истории закреплены, длинный список прокручивается.
- Лобби: три ясно отделённых шага подключение → локальные ресурсы → участники/готовность. Русская обёртка file picker и «Зерно генерации», техническая диагностика вторична. Все существующие IDs, права хоста и ready-before-generation сохраняются.

## Ошибки и границы

Нет новых механик, DTO, фиктивных сводок и изменения экономики. Новые оригинальные ассеты не подменять: отсутствующие показывать компактно и честно. Отсутствующий capacity/локализация/icon — явный fallback. Ошибка команды и обрыв связи остаются заметными, не скрываются вместе со штатным ACK. Динамический текст через textContent. Открытие/закрытие details не отправляет команды.

Приёмка: целевые Node-тесты поведения и клиентских регрессий, независимое ревью diff, браузерная проверка компоновки на двух 16:9 и состояний доступных панелей. В отчёте по каждому ID отделить исправленное, частичное и зависимое от источников; недоступный browser/runtime не объявлять PASS. Общая визуальная приёмка пользователя остаётся отдельной.
