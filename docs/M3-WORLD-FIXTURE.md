# M3 — фиксированный тестовый мир

Статус: конкретизация согласованных 16 систем; численный профиль N01 согласован пользователем 12 октября 2026 ответом «Да, для M3 подходит». Это временный технический профиль только M3. Не переносить его в production-генератор как ванильную формулу. [Время/движение](M3-TIME-AND-MOVEMENT.md), [визуальный профиль](M3-ASSET-MANIFEST.md).

## Топология и связи

Системы S01…S16: сетка 4×4; индекс `i=4*row+column+1`, row/column=0…3. Галактическая позиция `(100*column,0,100*row)`. Гиперлинии соединяют только соседей по горизонтали/вертикали: 24 недублированных двусторонних ребра, сортировка концов по ID. Это ручной fixture, не генерация по seed; координаты галактики не localPosition системы.

Первый player-slot → empire1, S01; второй → empire2, S16. В каждой системе одна неподвижная звезда star.g и одна planet.continental; только стартовые планеты имеют колонии. В стартовых системах по одной station.outpost.mammalian и флоту из трёх corvette, без постройки/боевых компонентов. Владение привязывается к стабильным server IDs, не порядку участников в очередном snapshot. Наблюдатель не занимает player-slot.

Экономика/начальные настройки колоний наследуют M2 без нового баланса; foreign body видим, foreign economic report не выдаётся. Дополнительная скрытая test-сущность используется только в негативном тесте проекций, не меняет публичное число 16 систем или экономику.

## Согласованные параметры N01

| Параметр | Значение M3 | Основание |
|---|---|---|
| Локальная система | Круг радиуса 150; допустимы точки внутри/на окружности | Техническая fixture, не вывод из SYSTEM_MIN_INNER_RADIUS |
| Star/planet/station | `(0,0)`, `(50,0)`, `(30,0)` соответственно | Фиксированные тестовые позиции, не ванильные орбиты |
| Начальная позиция флота | `(0,-100)` | Внутри радиуса, не совпадает с телами |
| Exit/entry | Радиус 140; направление нормализованного вектора между галактическими позициями концов ребра; entry у назначения направлен к источнику | Собственная воспроизводимая геометрия теста, не восстановленная генерация Stellaris |
| Скорость флота | 7,2 локальной единицы/игровой день | Corvette 160 × SHIP_SPEED_SCALE 0.045, базовые двигатели I, без модификаторов/разгона |
| Подготовка | 15 игровых дней | HYPERLANE_WINDUP 150 / 10, Hyper Drive I |
| Сам переход | Фиксированно 5 игровых дней на ребро | Согласованная временная замена неизвестной формулы только для M3 |
| Winddown | 0 | HYPERLANE_WINDDOWN=0 |

Единицы локальной сцены условно сопоставлены исходным units для теста; визуальный масштаб моделей задаётся отдельно и не меняет скорость. Столкновений с телами нет по согласованному упрощению M01; движение может пересекать их визуальную проекцию. Цель вне радиуса отклоняется, не clamp к окружности. Точная цель устанавливается при прибытии, без ванильного порога move_to=5.

Выходы по разным рёбрам могут иметь одинаковое направление лишь при изменении fixture; текущая сетка не имеет такой неоднозначности. Ребро с совпадающими центрами систем отклоняется на валидации мира. ID не выводятся из float-координат. Модель station — визуальная, не разрешение докинга/ремонта/производства.

## Приёмка

16 систем/24 рёбер; 16 star/planet, две колонии/станции/флота; каждый fleet имеет shipCount=3. Путь S01→S16 содержит 6 рёбер; равные пути выбираются стабильно по правилу контракта движения. Validate проверяет ссылки, player-slot, одинаковый material profile, конечные координаты, все exits внутри системы, отсутствие тайного использования непроверенного body bbox в навигации. Render stress 200 экземпляров — отдельная сцена, не новая галактика/экономика.
