## Client and failure contract

Reviewed conditional feature inventory extension (`e4d8ad99`): `blocker.d_failing_infrastructure`, `blocker.d_decrepit_dwellings`; passive `feature.d_hot_springs`, `feature.d_rushing_waterfalls`, `feature.d_tempestous_mountain`, `feature.d_veiny_cliffs`, `feature.d_prosperous_mesa`, `feature.d_rich_mountain`, `feature.d_rugged_woods`, `feature.d_fertile_lands`, `feature.d_black_soil`. Other selected IDs use their same-name local `gfx/interface/icons/deposits/` texture. All eleven are BGRA8 98×75, 2D, one mip/frame. No live instances, clearance effects or universal continental initialization are inferred. Hive/machine/Ark variants remain separately pending, without aliases.

Additive `profile.planetImages` is a Map keyed by the IDs above, each `{image:{width,height,rgba:Uint8Array},frames,frame:1,spriteId,sourcePath,border:{x,y}}`; image arrays are borrowed from the shared decoded image store and transferred once by the existing worker collector. Assets do not enter game DTOs; game DTOs carry only `imageDefinitionKey`.

`m3-planet-images.mjs` exports `preparePlanetImages(profile,{signal,maxDecodedBytes,...DOM injections})`. It stages selected frame PNG URLs without DOM mutation, then returns `{decodedBytes,get(id),dispose()}`. `get` yields immutable `{url,width,height}`; unknown/disposed access throws. Caller owns the handle, swaps it only after all staging succeeds, and disposes superseded/teardown handles. Cancellation/failure releases staged URLs/canvases, preserving the caller's previous handle. A zero-copy clamped view supplies Canvas2D; source pixels are unchanged. Adapter peak source/frame scratch plus retained derived image reservation is limited to 16 MiB. Browser URL/blob overhead and full process RAM are not claimed measured.

Worker cancellation uses existing worker termination; stale results never publish. Full profile staging/hash recheck completes before ready. Missing/malformed definitions, mismatched sprite paths, unsupported DDS dimensions/codec/faces/mips, memory overflow or changed hashes visibly fail atomically; old valid profile remains usable under existing replacement rules. No network asset transmission, shader execution or persistent derivative cache.

Acceptance: real-source manifest parity/digest and all selected bindings, negative altered/missing/duplicate binding and DDS cases, decode budget preflight, worker import/recheck/cancel regressions, adapter frame/lifetime/rollback tests, and actual browser PNG preparation.
