## Entry and exit

- Track each actual architectural question delivered to the human: exact question, context/base commit, affected operation, options/tradeoffs and delivery timestamp in the existing handoff or open-question entry. An internal reference inquiry or missing native formula is not automatically a human architectural question.
- If that question remains unanswered for **more than ten minutes**, mark its dependent work `waiting` at the next available coordination check. Measure from delivery, not drafting or first investigation; no duplicate timer automation or promise of an exactly timed wakeup.
- Elapsed time supplies neither an answer nor approval. Block only operations that require that answer. Preserve the question and evidence; never silently select an option, narrow the agreed scope, change privacy/transactions or substitute a vanilla formula.
- An answer ends waiting for that question. Record the accepted decision, recheck affected contracts and resume dependent work at a safe boundary. Multiple questions retain separate timers/dependencies; one answer does not resolve the others. Finish or safely hand off the current atomic task before switching priorities.
