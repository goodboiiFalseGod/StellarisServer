## Bounded core transfer correction

Following reference answer `01a13064-8af0-7013-84c2-410ea7a72ccd`, five core-only candidates were rendered at identical far/near 1280×720 canvases, DPR 1, selection null, v5 source profile/digests above. All source arrays, half intensity, geometry, ONE/ONE and other passes were fixed. No tonemapping was enabled. Ten captures `core-{raw-srgb,linear-srgb,raw-output,raw-alpha-srgb,linear-alpha-srgb}-{near,far}.png` and `core-transfer-comparison.json` remain outside Git in the same visualization directory.

Raw RGB followed by sRGB output was the bright square-footprint baseline. Piecewise sRGB EOTF on the filtered sample followed by sRGB output substantially reduced the broad footprint, preserving luminous central detail. Raw output without encoding also darkened edges but bypassed the output transfer for this pass. Alpha attenuation softened the footprint but introduced additional authored-shader deviation; combining linearization and alpha gave a more subdued core. The transfer-only `linear-srgb` candidate is selected: explicit browser calibration, no RGB alpha multiplication and no invented spatial mask. Independent diff/image review found no actionable P1/P2, confirmed visible improvement, and ran 6 focused tests successfully. Full real-source Node suite after production correction: **127 PASS, 0 FAIL, 0 SKIP**; diff check passes.
