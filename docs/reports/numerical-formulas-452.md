## Construction speed: accepted human rule

Let `B` be base duration in a consistent time unit and `s` the applicable speed bonus expressed as a dimensionless fraction (`+50%` means `.50`, not `50`). For the positive-denominator examples authorized here, `T = B / (1+s)` in the same time unit as `B`.

| Human-accepted example | Unquantized duration |

| `B = 10 years`, `s = .50` (+50%) | `10 / 1.5 = 6.666… years` |
