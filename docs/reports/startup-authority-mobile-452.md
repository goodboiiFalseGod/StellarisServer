## Rural and carrier dependencies

The ordered startup chain is explicit: rural variables → separate stationary/mobile authority scripts → species → ethics → origins → civics → rural placement → starting resources → native validation (`common/scripted_effects/01_start_of_game_effects.txt:1593–1693`). Founder/owner, colony and carrier scopes must remain distinct. `game_start.12` also invokes population setup and final pass before ship-specific Ark setup (`events/game_start.txt:1724–1794`); buildings alone do not initialize the full economy.

- Baseline rural variables are 2 generator, 2 mining, 3 farming; Ark reactor cap 2 and basic-deck count 1 (`game_start/rural_districts_initializer.txt:15–35`). `origin_default` adds one generator and either one farming or mining request according to `country_uses_food_game_start` (`origin_default.txt:12–56`). The food trigger tests any organic species, bio-ships or catalytic economy (`common/scripted_triggers/00_scripted_triggers_ai.txt:52–59`). This is not an authority-only rule.
- Species hooks can replace rural requests: Lithoids set 2/5/0 (`game_start/species_lithoids.txt:9–29`); individualist machines add an assembly plant and set 3/4/0 (`species_individual_machine.txt:9–31`). They are not automatically selected by the current accepted roles. Origin/civic hooks follow these changes.
- `rural_districts_placement.txt:6–23` caps Ark energy requests. Ordinary planets use resource-cap clamps; `pc_machine` instead requests `district_nexus_1` + `zone_energy_nexus` and `district_nexus_2` + `zone_minerals_nexus` (:33–105,125–186). These class branches are not triggered merely by machine authority.
- On `pc_ark`, energy becomes `district_ark_generator`; there are no mining districts. Basic decks receive `zone_ark_food` if the final farming variable is positive, otherwise `zone_ark_harvest`; Ark farming is handled by that branch, not a normal farming district (:91–99,174–216,284–289). Thus the unselected biological/lithoid/service-trait distinction can change the accepted Voidfarers startup zone; do not hardcode the food branch from the word “individualist.”
- District helper addition depends on free slots and can enlarge a planet below size 25; it is not an unconditional final count (`01_start_of_game_effects.txt:4624–4649`). Accepted stationary templates choose neither continental class nor size 20. The ordinary initializer's ideal class/size 18–21 is only a candidate (`common/solar_system_initializers/empire_initializers.txt:14–15,76–88`).
- Accepted Ark class is `pc_ark`, size 9, district set `nomad` (`common/planet_classes/06_planet_classes_nomads.txt:92–98`), with civilian T1 carrier under accepted doc28. Preserve ship-colony identity, actual system and moving capital dependencies. `origin_default_nomads` does not by checked source inherit `origin_default` district increments or prosperity. Default-origin final pass adds `prosp_uni_mod` or Gestalt variant for 7200 days (`01_start_of_game_effects.txt:2471–2492`); do not omit reachable numerical modifiers.
