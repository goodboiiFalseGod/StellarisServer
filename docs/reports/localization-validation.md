## Передача и ограничения

Координация выполнена до кода с владельцами UI и каталогов. UI owner единолично подключает staging к `importSource` и callback к panel/topbar; catalog owner передаёт source-bound optional keys, сохраняя ID. С 14 октября общий кандидат собирает отдельный координатор объединения систем в ветке `integration/playable-systems-rc`; координатор планет продолжает свой срез. Файлы локализации не включаются в графический manifest/decoded budget.

При texture-only источнике недостающую локализацию следует показать явно и предложить выбор папки; после ошибки/отмены прежний снимок остаётся. Публикация нового snapshot вместе с profile, смена источника, logout/stale lifecycle — ответственность UI owner и требуют потребительских проверок. Прямой File System Access в Chrome, реальный отзыв OS-разрешения и браузерная проверка видимых подписей здесь **не выполнены**. Модульные тесты их не заменяют.

Профиль имён не удостоверяет неизменность байтов установки; native load order, грамматика, числовое форматирование, rich DOM renderer и scripted scope не объявляются реализованными. Исходный шаблон сохранён, неизвестные ссылки/scope видимы и диагностируются. Подключение всех UI-потребителей не объявляется завершённым этим отчётом.
