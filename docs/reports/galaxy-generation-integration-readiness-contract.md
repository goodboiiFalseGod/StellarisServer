# GALAXY-INTEGRATION-READY-001

October 13, 2026. Direct user request: continue until generation can be connected
to a settings-enabled lobby and a playable test prototype.
Vanilla completeness is a development direction; native-bit identity is not a gate. This task
prepares an isolated producer/contract/smoke harness; it does not change the planet prototype,
Session/M3/server/client, or merge/push to stable.

## Verifiable integration result

1. One API accepts an immutable lobby request: seed, scenario, shape, density,
   content parameters, and ordered player/start-context slots; validates before world publish.
   The option catalog is source-derived; invalid/incompatible values are diagnosed.
2. Generation performs placement→relaxation→group/graph→final connected hyperlanes,
   allocates unique home systems and creates star/planet/moon descriptor objects from
   vanilla definitions. There is no hardcoded 16-system fixture or synthetic single planet
   in every ordinary system. Unrecoverable required-content errors do not publish a world.
3. Immutable consumer-neutral world DTO contains stable IDs, galaxy/local coordinates,
   lanes, bodies/parent-orbit relations/classes/sizes, start allocations, and source/seed
   manifest. Core does not depend on Session/M3 and does not change economic rules.
4. Script/startup/visual/ownership dependencies are explicit. Consumer API does not present
   queued/unsupported effects as executed. Prototype profile and strict vanilla
   readiness are distinct: an unsupported required operator blocks strict mode,
   and every allowed deferred/approximate path is visible in output diagnostics/coverage.
5. Integration smoke runs the real generator against a vanilla snapshot: at least
   tiny200, varied seeds/shapes/density/slots, deterministic repeat, connectivity,
   homes/counts/links/classes/orbits/source stability, and controlled invalid settings.
   Handoff describes mapping into the existing prototype schema and repeat commands.
6. Each substantial code slice receives independent actual-diff/contract review,
   then only owned paths are committed. Source snapshots/metadata are preserved; game assets,
   upstream Triangle/binaries, and local inventory are not added to Git.

## Sequence

Runtime catalog/isolated reader (all initializer/star/planet definitions) →
PruneAndMaterializeHyperlanes/settings → partitions/home allocation → descriptor
execution/content/runtime hooks → unified world producer/lobby options → integration
smoke/consumer handoff/review. The coverage manifest is updated according to actual support.

block progress. Documented approximations must preserve valid content and world invariants;
